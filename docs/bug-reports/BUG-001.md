# BUG-001 日视图短事件气泡被标题撑宽，时间比例失真

- 报告人：Gaozhuoyi
- 发现时间：2026-10-12 09:30
- 严重程度：中
- 优先级：P2
- 状态：待修复
- 复现概率：必现

## 环境

- macOS
- Chrome 最新版
- SmartPlanner Web
- 视口宽度 1600 px

## 复现步骤

1. 进入日视图。
2. 在 10:00 创建一个普通事件，结束时间为 10:15。
3. 将事件标题填写得较长，例如“和队友确认下一阶段需求范围”。
4. 观察时间轴上事件气泡的宽度。

## 预期结果

气泡宽度应主要反映 15 分钟的真实时长，标题超出时使用省略号或在别处展示完整标题。

## 实际结果

气泡为了保证标题可读被明显拉宽，视觉上占据了接近一小时的时间范围，和时间轴刻度不一致。

## 影响

用户可能误判事件实际占用时长，短事件较多时还会挤压相邻事件。

## 建议

恢复按真实时长计算宽度；标题通过换行、省略号或详情面板展示，不再反向撑宽时间块。
