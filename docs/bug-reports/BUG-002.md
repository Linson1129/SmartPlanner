# BUG-002 周视图容器标题被子事件覆盖，无法直接进入容器

- 报告人：Gaozhuoyi
- 发现时间：2026-10-15 18:30
- 严重程度：中
- 优先级：P2
- 状态：待修复
- 复现概率：必现

## 环境

- macOS
- Chrome 最新版
- SmartPlanner Web
- 周视图

## 复现步骤

1. 在日视图创建一个容器事件，例如 20:00-21:00 的“晚间并行”。
2. 在容器内创建两个子事件，例如“洗衣机运行”和“客厅拉伸”。
3. 切换到周视图，滚动到 20:00 附近。
4. 尝试点击容器的标题区域。

## 预期结果

容器标题应保持可见且可点击，点击后打开容器详情。

## 实际结果

子事件覆盖了容器标题区域，容器的文字被遮住，点击时优先命中子事件，容器入口不明显。

## 影响

周视图下容器内的并行任务可查看，但容器本身难以进入，用户需要切回日视图操作。

## 建议

将容器标题放在子事件上层的独立区域，或为容器增加右侧固定的打开入口；子事件仍保持可点击。
