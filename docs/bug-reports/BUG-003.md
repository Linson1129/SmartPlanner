# BUG-003 关闭设置弹窗会直接丢弃未保存修改，没有提示

- 报告人：Gaozhuoyi
- 发现时间：2026-10-19 09:30
- 严重程度：低
- 优先级：P3
- 状态：待修复
- 复现概率：必现

## 环境

- macOS
- Chrome 最新版
- SmartPlanner Web
- 设置弹窗

## 复现步骤

1. 打开设置。
2. 修改称呼、预期收工时间或节假日偏好。
3. 不点击“保存设置”，改为点击右上角关闭、点击遮罩或按 Esc。
4. 重新打开设置。

## 预期结果

如果存在未保存修改，应提示“放弃修改”或自动保留草稿。

## 实际结果

弹窗直接关闭，刚才的修改全部丢失，没有任何提示。

## 影响

用户容易误以为修改已经生效，尤其是只改了一个选项时。

## 建议

增加未保存修改检测，关闭时二次确认；或在关闭时恢复并提示未保存。
