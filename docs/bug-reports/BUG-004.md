# BUG-004 天气服务不可用时界面静默隐藏，无法判断是否加载失败

- 报告人：Gaozhuoyi
- 发现时间：2026-10-22 18:30
- 严重程度：低
- 优先级：P3
- 状态：待修复
- 复现概率：偶现，依赖网络或天气服务状态

## 环境

- macOS
- Chrome 最新版
- SmartPlanner Web
- 天气服务断网或后端天气接口返回不可用

## 复现步骤

1. 正常打开日视图，确认顶部有天气信息。
2. 断开网络，或让天气服务返回 `available=false`。
3. 刷新页面并切换到日视图或周视图。

## 预期结果

界面应显示“天气暂不可用”或加载失败状态，帮助用户区分没有预报和服务异常。

## 实际结果

天气区域直接消失，没有任何提示，用户无法判断是天气服务故障还是本来没有数据。

## 影响

天气敏感事件的提醒依据不完整，用户可能误以为当天没有天气风险。

## 建议

保留一个不可用状态占位或小提示；不需要展开长说明，只显示状态。
