# BUG-005 一句话排期在当天输入过去的星期时间会生成过去日期

- 报告人：Gaozhuoyi
- 发现时间：2026-10-26 09:30
- 严重程度：中
- 优先级：P2
- 状态：待修复
- 复现概率：条件必现

## 环境

- macOS
- Chrome 最新版
- SmartPlanner Web
- 一句话添加

## 复现步骤

1. 在周五下午 18:00 打开一句话添加。
2. 输入“周五下午3点开会”。
3. 解析并填入表单。
4. 观察生成的开始日期和时间。

## 预期结果

如果周五 15:00 已经过去，应生成下周五 15:00，或在表单中明确提示时间已过去并要求确认。

## 实际结果

解析结果仍使用当天日期，生成一个已经过去的 15:00 事件，保存时没有专门提示。

## 影响

用户容易把新安排保存到过去，造成时间轴位置错误和提醒逻辑异常。

## 建议

当解析结果早于当前时间时，自动顺延到下一个周期，或在草稿预览中给出明显的时间已过提示。
