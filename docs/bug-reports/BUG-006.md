# BUG-006 容器边框未覆盖子事件结尾，视觉上像子事件超出容器

- 报告人：Gaozhuoyi
- 发现时间：2026-11-26 10:15
- 严重程度：中
- 优先级：P2
- 状态：已修复
- 复现概率：必现

## 环境

- macOS
- Chrome 最新版
- SmartPlanner Web
- 日视图、周视图

## 复现步骤

1. 创建一个 14:00-16:00 的容器事件。
2. 在容器内创建一个或多个与容器时间范围重叠的子事件。
3. 为子事件设置较长标题。
4. 观察日视图中容器右边框与子事件气泡的右侧边界。

## 预期结果

容器边框完整包住子事件，子事件不越过容器右边框；容器与子事件的时间范围保持一致。

## 实际结果

子事件为了显示完整标题被撑宽，右侧覆盖了容器边框，导致容器看起来只框住了开头，没有框住结尾。

## 影响

用户会误以为子事件超出了容器范围，容器与子事件的关系在视觉上不成立。

## 修复

日视图中把子事件宽度限制在父容器右边界以内，并在右边界前留出间距；周视图同步限制子事件高度不超过父容器结束位置。
